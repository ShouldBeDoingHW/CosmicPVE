# CosmicPVE

CosmicPVE is a NeoForge 1.21.11 cooperative PvE Minecraft mod for singleplayer and groups of up to four players.

The intended game design is documented in `docs/Cosmic_Design.md`. The reusable technical foundation and planned implementation sequence are documented in `docs/ARCHITECTURE.md`.

## Development

- Java 21
- Minecraft 1.21.11
- NeoForge 21.11.45
- ModDevGradle 2.0.144
- Gradle 9.2.1

Build with `./gradlew build` on macOS/Linux or `gradlew.bat build` on Windows.
